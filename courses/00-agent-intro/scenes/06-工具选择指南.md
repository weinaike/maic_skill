## 讲稿

了解了我们的学习闭环之后，接下来要解决一个非常实际的问题——在这门课里，我们到底用哪个 Agent 工具？

这页就是工具选择指南。大家的技术背景各不相同，所以我会根据三种不同情况，给出最合适的推荐方案。 @[text_Gjki9Yfx]

第一种情况：如果你平时熟悉终端操作，我强烈推荐 Claude Code。它是命令行驱动的，功能非常强大而且灵活。比如你做科研时习惯用 shell 跑脚本、处理数据，那 Claude Code 会和你的工作流无缝衔接，让你如鱼得水。 @[text_FtFkvU3j]

第二种情况：如果你不太熟悉终端操作，完全没关系，推荐使用 WorkBuddy。它提供图形界面的引导，上手非常简单，你不需要记住任何命令，通过点击和拖拽就能完成大部分操作。对科研人员来说，这个门槛低很多。 @[text_INU5umJZ]

第三种情况：如果你已经有了自己常用的 Agent 工具，比如 Cursor 之类的编辑器，完全可以继续用你熟悉的工具。保持你的使用习惯就好，不需要为了这门课专门切换。工具顺手最重要。不过如果你已经熟悉命令行终端，我建议使用 ClaudeCode, 它对于 MCP和Skill的协议兼容好。同时没有过渡封装，操控性会好些。 @[text_089p9OZq]
