## 讲稿

好，那我们正式进入今天的主题——Agent，也就是智能体技术。

这门课叫"Agent基础与应用"。从名字就能看出来，我们既会讲清楚 Agent 到底是什么、底层原理是怎样的，也会带大家动手实践，把学到的知识真正用起来。 @[text_2FzIQGyp]

我们的核心目标是：帮助大家理解 Agent 的底层原理，并且搭建出适合你自己需求的定制化智能体。不是简单地用现成工具，而是真正理解它怎么工作的，这样你才能根据科研中的实际问题灵活配置和调整。 @[text_dsPn3fN9]

这门课面向的主要是一线科研人员。无论你是做文献调研、实验数据分析，还是写论文、管理项目进度，都可以利用已有的Agent工具，或者定制自己的Agent 来提升工作效率 @[text_8SuVIoxX]
