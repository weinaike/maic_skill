## 讲稿

刚才我们看完了四个模块的内容概览，那这门课具体怎么上呢？我们为大家设计了五种多元化的学习方式，帮助大家全面建立学习预期。 @[text_bjIpgE_B]

第一种是理论讲解。帮助大家理解 Agent 的底层原理。这是打地基的环节，原理搞清楚了，后面用起来才得心应手。 @[text_4NCSlC3_]

第二种是交互体验。我们会用交互式页面，让大家直观地感受那些抽象概念。比如 Agent 的推理过程、工具调用机制，亲身体验一下就明白了。 @[text_XXVmxn_d]

第三种是 项目实战演练，这也是课程的核心环节。大家会接入课程的 MCP 工具，跟你的本地 Agent工具一起协作完成项目任务，完成项目目标的同时，你也就对课程内容有更深的体会 @[text_NiMQsivg]

第四种是课外题。需要大家自主查找相关扩展资料来完成，这部分内容，课程内之后提及但不会深入，需要你自己去了解和学习。 @[text_wK81n0bM]

最后是 QA 在线答疑。课程中遇到任何问题都可以随时提问，课程设置了群聊区，并配置了AI老师，如果AI无法解答你的问题， 我看到也会补充。我们还有微信群，方便日常交流和分享。通过这五个环节，期望能够让大家有个好的学习体验。 @[text_ttXuCnD2]
