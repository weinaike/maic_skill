## 讲稿

刚才我们聊到的那些痛点，这门课到底怎么帮大家解决呢？整个课程分为四大模块，采用递进式学习路径——从底层原理出发，一步步走到高阶应用。每个模块都是前一个的自然延伸，环环相扣。 @[text_aFycsoN8]

第一个模块是基础概念。我们会深入 Token 和 Prompt 的相关知识点。很多人觉得 Prompt 就是写几句话，但当你真正理解一个Agent是怎么管理各类Prompt，模型怎么'读'你的输入，对于智能体的工作会更加深入。 @[text_0YhJEGd4]

第二个模块进入 Agent 本质。这部分非常实操——一起搭建工作流、搭建自由任务 Agent，还会拆解成熟 Agent 案例，搞清楚别人是怎么把 Agent 做好做稳的。 @[text_UUaeHOwx]

第三个模块是基础定制，重点讲 MCP 工具开发方法和 Skill 开发方法。这就是能力扩展——让 Agent 用上你自己定义的工具，真正为科研场景服务。 @[text_zxBGDzcx]

最后第四个模块，进阶定制，涉及 Agent 上下文管理和工作模式，帮你应对真实科研中复杂、长周期的任务。四个模块走完，大家就具备了从原理到实战的完整能力体系。 @[text_43Vq7gNw]
